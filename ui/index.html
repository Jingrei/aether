How to process all system audio
  1. Install a virtual audio cable (for example the free VB-Audio Virtual Cable).
  2. In Windows Sound settings, set CABLE Input as the default output device.
  3. Leave Source and Play on set to Automatic. Aether captures the cable and plays the processed sound on your real headphones or speakers.
  4. For true surround from games and movies, set the cable to 7.1 in the Windows Sound control panel (Configure speakers). Aether renders every channel in its own virtual position.
